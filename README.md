# MiPrimerHolaMundo
Repositorio para las actividades de la asignatura Estructura de Datos del semestre 2 de 2026

#MiPrimerComentario

Este proyecto, desarrollado en Java, tiene como objetivo implementar y gestionar una matriz de objetos aplicando los principios de la programación orientada a objetos. La aplicación permite almacenar, organizar y manipular información mediante estructuras bidimensionales opuestas por instancias de una las personalizada.
